# Consumer-Analytics-Project-SQL — Consumer Goods Analysis
AtliQ Hardwares Consumer Goods Data Analytics SQL Project
Created by: Manish Kumar
Welcome to my AtliQ Hardwares Consumer Goods Data Analytics Project repository. This repository contains SQL queries and project materials developed for the Consumer Goods domain section of the Codebasics Data Analytics Bootcamp.
Overview
This project explores a consumer goods dataset for AtliQ Hardwares, a global hardware company offering PCs, printers, mice, computers, and related products. The goal is to address 10 ad hoc business requests using SQL and uncover useful trends and insights.
Project Scope
The project uses SQL querying and analytical techniques to answer business questions about AtliQ Hardwares' consumer goods operations. The findings are intended to support data-driven decision-making.
Dataset Description
The dataset covers consumer goods information, including sales, inventory, products, and related performance metrics. It serves as the foundation for the analysis.
Project Objectives
- Use SQL queries to answer 10 ad hoc business requests.
- Analyze consumer goods sales, inventory, and performance metrics.
- Identify trends and insights that can support business decisions.
Key Insights
Area	Insight
Unique products	Increased from 245 in 2020 to 334 in 2021.
Leading product segment	Notebook had the highest product count, with 129 distinct products.
Accessories segment	Product count increased by 34 from 2020 to 2021.
Retailer discounts	Flipkart had the highest average pre-invoice discount at 30.83%.
Sales performance	The relatively low sales in March and April of FY 2020 improved in FY 2021.
Gross sales by channel	The Retailer channel contributed 73.22% of gross sales.
